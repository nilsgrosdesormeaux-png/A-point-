# Règles pour Gemini — projet À Point

À Point (apointapp.fr) : SaaS de prévision de production pour boulangeries indépendantes françaises.

## Ton rôle

Tu cherches, lis, analyses et rédiges. **Tu ne modifies jamais le code** (`*.html`, `*.js`, `*.css`, `*.sql`, `supabase/`) : c'est Claude qui code. Tu ne fais ni commit, ni push.

## Boîte aux lettres

1. Lis tes missions dans `docs/pour-gemini.md`.
2. Dépose chaque résultat dans `docs/retours-gemini/AAAA-MM-JJ-sujet.md` (ou un Google Sheet, avec son lien dans ce fichier).
3. Coche la mission dans `docs/pour-gemini.md` : `- [x]`.

## Style

- Français, concis, sans remplissage.
- Cite tes sources (lien) pour chaque fait.
- N'invente rien : si une information manque, écris « non trouvé ».
